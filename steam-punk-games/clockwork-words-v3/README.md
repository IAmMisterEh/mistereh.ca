# Clockwork Words v3.0 - Spiral Escape

A steampunk typing game where letters spiral inward from the outer edges, and you must type them before they reach the center!

## Game Concept

Spiral Escape transforms the traditional typing game into a dynamic survival experience:

- **Spiral Path System**: Letters spawn at the outer edge of a rotating spiral and move toward the center
- **Progressive Difficulty**: 7 levels with increasing speed and spawn rates
- **Streak Bonus**: Chain together successful presses for massive points
- **Visual Feedback**: Real-time keyboard display shows what you've typed

## How to Play

1. Press **INITIATE SEQUENCE** to start
2. Letters will appear on the spiral arms
3. Type the letters shown in the highlighted bubble
4. Each correct press removes the letter and sends it spiraling inward
5. If a letter reaches the center, game over!
6. Complete 7 levels of progressively difficult words

## Features

- **60fps Canvas Rendering**: Smooth spiral animation
- **Steampunk Aesthetic**: Brass, gold, and steam effects
- **Keyboard Visualization**: See your keys light up as you type
- **Streak System**: Build streaks for exponential scoring
- **Progressive Levels**: 
  - Level 1: Home row basics (word, data, code, type, byte)
  - Level 2: Top row characters (speed, input, logic, script)
  - Level 3: Bottom row characters (system, power, force, pulse)
  - Levels 4-7: Mixed characters and symbols
